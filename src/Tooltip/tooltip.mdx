# Tooltip

A popup that appears when an element is hovered or focused, showing a hint for sighted users. Based on Base UI Tooltip for accessibility and consistent behavior.

## Basic Usage

```tsx
import { Tooltip } from '@developmentsnil/awake-ui/tooltip';
import '@developmentsnil/awake-ui/style.css';

<Tooltip.Provider>
  <Tooltip.Root>
    <Tooltip.Trigger aria-label="Bold">
      <button>Hover me</button>
    </Tooltip.Trigger>
    <Tooltip.Portal>
      <Tooltip.Positioner>
        <Tooltip.Popup>
          <Tooltip.Arrow />
          Tooltip content
        </Tooltip.Popup>
      </Tooltip.Positioner>
    </Tooltip.Portal>
  </Tooltip.Root>
</Tooltip.Provider>
```

## Multiple Tooltips

Coordinate multiple tooltips with a single Provider.

```tsx
<Tooltip.Provider>
  <div style={{ display: 'flex', gap: '16px' }}>
    <Tooltip.Root>
      <Tooltip.Trigger aria-label="Bold">
        <button>Bold</button>
      </Tooltip.Trigger>
      <Tooltip.Portal>
        <Tooltip.Positioner>
          <Tooltip.Popup>
            <Tooltip.Arrow />
            Bold text
          </Tooltip.Popup>
        </Tooltip.Positioner>
      </Tooltip.Portal>
    </Tooltip.Root>
    <Tooltip.Root>
      <Tooltip.Trigger aria-label="Italic">
        <button>Italic</button>
      </Tooltip.Trigger>
      <Tooltip.Portal>
        <Tooltip.Positioner>
          <Tooltip.Popup>
            <Tooltip.Arrow />
            Italic text
          </Tooltip.Popup>
        </Tooltip.Positioner>
      </Tooltip.Portal>
    </Tooltip.Root>
  </div>
</Tooltip.Provider>
```

## Positioning

Control tooltip position with the `side` prop.

```tsx
<Tooltip.Positioner side="top">
  {/* popup */}
</Tooltip.Positioner>
```

Available positions: `top`, `bottom`, `left`, `right`

## Controlled Mode

Control tooltip open/close state programmatically.

```tsx
const [open, setOpen] = useState(false);

<Tooltip.Root open={open} onOpenChange={setOpen}>
  {/* trigger and popup */}
</Tooltip.Root>
```

## With Viewport

Ensure tooltip stays within viewport boundaries.

## Props

### Tooltip.Provider

- `children` - Tooltip Root components to coordinate
- `delay` - Delay before tooltip appears (in milliseconds)
- `delayClose` - Delay before tooltip closes (in milliseconds)

### Tooltip.Root

- `open` - Controlled open state (boolean)
- `onOpenChange` - Callback when open state changes `(open: boolean) => void`
- `defaultOpen` - Default open state for uncontrolled usage
- `closeDelay` - Delay before closing (in milliseconds)

### Tooltip.Trigger

- `aria-label` - Accessible label for the trigger (required for accessibility)
- `className` - Additional CSS classes
- `disabled` - Disables the trigger and tooltip

### Tooltip.Positioner

- `side` - Position relative to trigger: `"top" | "bottom" | "left" | "right"`
- `align` - Alignment on the specified side
- `sideOffset` - Distance from the trigger (in pixels)
- `alignOffset` - Offset from the alignment point

### Tooltip.Portal

- `container` - Container element for portal rendering
- `disabled` - Disable portal rendering

### Tooltip.Popup

- `className` - Additional CSS classes
- `id` - Unique identifier for the popup

### Tooltip.Arrow

- `className` - Additional CSS classes
- `width` - Arrow width
- `height` - Arrow height

### Tooltip.Viewport

- `className` - Additional CSS classes
- `padding` - Padding from viewport edges
