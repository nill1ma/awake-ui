# Dialog

Componente composto (`Dialog.Root`, `Dialog.Trigger`, `Dialog.Portal`, `Dialog.Popup`, `Dialog.Title`, `Dialog.Description`) para construir diálogos com overlay e conteúdo já conectados via acessibilidade nativa do Base UI.

```tsx
import { Dialog } from 'awake-ui/dialog';
import 'awake-ui/style.css';

<Dialog.Root>
  <Dialog.Trigger>Open Dialog</Dialog.Trigger>
  <Dialog.Portal>
    <Dialog.Popup>
      <Dialog.Title>Dialog Title</Dialog.Title>
      <Dialog.Description>Dialog Description</Dialog.Description>
    </Dialog.Popup>
  </Dialog.Portal>
</Dialog.Root>
```
