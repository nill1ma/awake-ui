# Switch

Component for creating toggle buttons with support for checked and disabled states.

## Basic Usage

```tsx
import { Switch } from '@developmentsnil/awake-ui/switch';
import '@developmentsnil/awake-ui/style.css';
import { useState } from 'react';

function SwitchExample() {
  const [checked, setChecked] = useState(false);
  return <Switch checked={checked} onCheckedChange={setChecked} />;
}
```

<Canvas of={SwitchStories.Default} />

## Props

- `checked` - Switch state (boolean)
- `onCheckedChange` - Callback when state changes
- `disabled` - Disables the switch
