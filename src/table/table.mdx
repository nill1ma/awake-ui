# Table

Componente composto (`Table.Root`, `Table.Head`, `Table.Body`, `Table.Row`, `Table.HeaderCell`, `Table.Cell`) para construir tabelas com elementos HTML semânticos nativos (`<table>`, `<thead>`, `<th>`, etc.), garantindo acessibilidade sem depender de nenhuma lógica adicional de JavaScript.

```tsx
import { Table } from '@developmentsnil/awake-ui/table';
import '@developmentsnil/awake-ui/style.css';

<Table.Root>
  <Table.Head>
    <Table.Row>
      <Table.HeaderCell>Nome</Table.HeaderCell>
      <Table.HeaderCell>Email</Table.HeaderCell>
    </Table.Row>
  </Table.Head>
  <Table.Body>
    <Table.Row>
      <Table.Cell>John Doe</Table.Cell>
      <Table.Cell>john.doe@example.com</Table.Cell>
    </Table.Row>
  </Table.Body>
</Table.Root>
```
